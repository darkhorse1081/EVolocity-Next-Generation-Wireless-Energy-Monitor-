# EVolocity Next-Generation Wireless Energy Monitor 
• Developed ESP32 firmware in C using ESP-IDF and FreeRTOS for a wireless energy-monitoring node sampling voltage and bidirectional current, streaming telemetry over Wi-Fi to a self-hosted server. • Implemented the ADC acquisition and calibration pipeline with 100 Hz sampling, averaging, line-fitting calibration, physical-unit conversion, auto-ranging between ±20 A and ±100 A channels, plus a 3000-sample circular RAM buffer, SNTP timestamping, ULP deep sleep wake-on-activity, and over-power buzzer alerting for offline race-day reliability.
